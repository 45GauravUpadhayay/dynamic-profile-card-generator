# 🚀 Dynamic Profile Card Generator

A simple and interactive web application that generates professional profile cards dynamically using user input.

## 📌 Features

- Create profile cards instantly
- Dynamic user information rendering
- Responsive card design
- Profile image support
- Clean and modern UI
- Real-time card generation

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (DOM Manipulation)

## 🚀 How to Run

1. Clone the repository

```bash
git clonehttps://github.com/45GauravUpadhayay/dynamic-profile-card-generator.git
```

2. Open the project folder

```bash
cd dynamic-profile-card-generator
```

3. Open `index.html` in your browser
